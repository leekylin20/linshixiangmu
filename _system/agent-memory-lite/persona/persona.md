# 临时项目 Agent 画像

更新时间：2026-06-07

## 高优先级规则

- 不把程序实体、运行时、技能、模型/cache、下载包、临时依赖放到 `C:\`。
- 默认使用 `E:\临时项目\_system` 存放通用工具和运行时。
- 项目专属依赖放在对应项目目录下。
- 新项目、安装、跑通命令后，必须回写 `_索引`。
- 不删除或移动现有项目目录，除非用户明确确认。
- 临时项目不是第二大脑，长期业务知识进入 `E:\obsidian`。

## 协作偏好

- 先读现有目录和规则，再动手。
- 能接到现有 `_索引` 的，就不要另起孤岛。
- 可复用工具要留下启动命令和保留理由。
- 一次性输出、旧 zip、备份目录先进清理候选，不直接删除。

## UI / 视觉工作偏好

- 工作台优先做真实可用界面，不做空泛 landing page。
- 批量提示词常用单行 TXT，避免生图软件按段落拆分。
- 直播间视觉项目要保留透视、机位、主体、负面词等稳定约束。

## 启动建议

每次处理 `E:\临时项目` 内的新任务前，优先查看：

- `E:\临时项目\AGENTS.md`
- `E:\临时项目\00-从这里开始.md`
- `E:\临时项目\_索引\README.md`
- `E:\临时项目\_system\agent-memory-lite\scenes\temporary-project.md`
