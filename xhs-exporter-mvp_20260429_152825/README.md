# 小红书主页笔记导出助手 MVP

这是一个最小可测试的 Chrome Extension Manifest V3 插件。

## 当前范围

只做以下能力：

- 支持小红书网页中的用户主页卡片采集
- 支持单条笔记详情页或详情弹窗的可见正文采集
- 支持详情正文追加/回填到同一份本地结果
- 支持在主页卡片上点击“采正文”，自动打开该笔记详情并回填正文到本地缓存
- 支持半自动打开下一条，以及下载当前已采详情中的可见媒体
- 仅采集当前页面已渲染且用户可见的内容
- popup 中展示页面类型、采集数量、前 10 条预览
- 支持导出 JSON 和 CSV
- 所有数据仅保存在本地 `chrome.storage.local`

## 明确不做

- 不做 fetch / XHR hook
- 不做接口监听
- 不做自动滚动
- 不做搜索页
- 不自动打开列表里的详情页补全文本
- 不做 Markdown 导出
- 不读取 Cookie、密码、手机号等敏感信息
- 不绕过登录、验证码、权限限制

## 文件结构

- `manifest.json`
- `content.js`
- `popup.html`
- `popup.js`
- `popup.css`

## 安装方式

1. 打开 Chrome 浏览器。
2. 进入 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择当前目录 `xhs-exporter-mvp_20260429_152825`。

## 使用方式

1. 在 Chrome 中打开小红书网页，并进入某个用户主页或单条笔记详情。
2. 点击浏览器工具栏中的插件图标。
3. 点击“开始采集”。
4. 查看采集数量和前 10 条预览。
5. 点击“导出 JSON”或“导出 CSV”。

## 半自动正文采集流程

1. 在用户主页点击“开始采集”，先建立当前可见笔记链接清单。
2. 手动打开一篇笔记详情页或详情弹窗。
3. 再点击“开始采集”，插件会把当前详情正文追加或回填到本地结果。
4. 关闭详情，打开下一篇，重复第 3 步。
5. 全部采完后统一导出 CSV。
6. 需要重新开始时点击“清空数据”。

## 卡片一键采正文

1. 在用户主页找到要采集的笔记卡片。
2. 点击卡片右上角“采正文”。
3. 插件会打开该笔记详情页。
4. 详情页加载后，正文会自动写入本地缓存。
5. 悬浮状态中的“正文”数量增加后，即表示已回填成功。

## 半自动下载流程

1. 在用户主页点击“开始采集”，建立链接清单。
2. 点击“打开下一条”，插件会在当前标签页打开第一条未采正文的链接。
3. 等详情页加载完成后，点击“开始采集”。
4. 点击“下载当前媒体”，下载当前详情中可见的图片或视频资源。
5. 重复“打开下一条 -> 开始采集 -> 下载当前媒体”。

## 当前采集字段

每条笔记尽量提取以下字段：

- `index`
- `noteId`
- `title`
- `content`
- `author`
- `likes`
- `image`
- `type`
- `link`
- `sourceUrl`
- `capturedAt`

## 已知限制

- 高度依赖当前页面 DOM 结构，页面改版后可能失效。
- 用户主页只采集当前页面已经渲染出来的卡片，不会自动滚动。
- 用户主页卡片通常没有正文；需要正文时，请打开笔记详情页或详情弹窗后再点击采集。
- 某些页面模板下，作者、点赞数、标题、正文可能为空。
- 页面识别只做了最小判断，识别并不完美。

## 建议测试点

1. 能否在开发者模式正常加载。
2. 打开小红书用户主页时，点击采集后是否返回卡片数据。
3. 打开单条笔记详情时，点击采集后 CSV 是否包含“正文”列。
4. CSV 用 Excel 打开时中文是否正常。
5. 标题或正文包含逗号、双引号、换行时导出是否正常。
