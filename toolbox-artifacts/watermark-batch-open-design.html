批量图片水印工具包

给 Windows 用户的一页式交付说明

这个工具把图片放入 input，通过 一键加水印.bat 调用本地 PowerShell 脚本， 按 config.ini 批量生成带文字水印的图片。默认输出到 output\水印结果_时间戳， 不覆盖原图，不联网，不需要 secret 或 API key。

入口 双击 bat 或传入目录参数
参数 文字、位置、透明度、字号、角度、递归
输出 新目录图片结果，可再打包 ZIP 分发
已验证样张 1080 × 1920 PNG

来源：本地测试输出 _package_watermark_test_output_bat\sample.png。本页只引用本地文件，不上传图片。

交付流程

1 解压工具包

保持 fonts、tools、input、output 和入口 bat 在同一目录。

2 放入图片

把需要处理的图片放进 input，或把图片目录拖到 一键加水印.bat 上。

3 检查配置

按需修改 config.ini，默认是中部三处文字水印、80% 透明度、小四字号。

4 查看结果

结果写入 output\水印结果_时间戳，原始输入文件保持不变。

命令行调用

一键加水印.bat "D:\图片目录"
一键加水印.bat "D:\图片目录" "D:\输出目录"

本地目录关系

  • input/：默认输入目录。
  • output/：默认输出目录，开启时间戳子目录。
  • config.ini：水印文字、位置、透明度、字号等参数。
  • fonts/：随包 Noto Sans SC 字体与 OFL 许可证。
  • tools/watermark.ps1：实际处理脚本。

默认配置

字段 当前值 说明
WatermarkText 图明索高清调试 写入图片上的文字水印。
Position middle-sides 图片中部左侧、中间、右侧三处。
Opacity 80 1-100，数值越高越明显。
FontSize small4 小四，约 12pt / 16px。
Angle -35 文字旋转角度。
Recursive false 默认不递归扫描子目录。
JpegQuality 92 JPG/JPEG 输出质量。

审核边界

  • 本页不执行 bat、PowerShell 或任何 shell 命令。
  • 工具运行不需要网络、secret、API key 或账号登录。
  • 默认输出新目录，不覆盖原图。
  • 已验证入口、字体加载和样张输出。
  • 适合进入低风险闭环，后续前端工作台仍只生成任务包和记录。

适合交付的原因

  • 目标用户清楚：普通 Windows 用户可以通过解压、放图、双击完成。
  • 风险面小：没有联网、没有 secret、没有自动采集或发布。
  • 验收标准明确：入口存在、配置存在、输出目录清晰、原图不被覆盖。
  • Open Design artifact 可以先作为说明页交付，不需要接真实执行。
