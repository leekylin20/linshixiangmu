AI Content Workflow

本地内容生产工作台的交付说明

这个工具是一个纯本地浏览器工作台，用 10 个阶段把高价值客群内容生产拆成卖点、买点、蓝海机会、爆文结构、选题矩阵、批量笔记、发布、复盘、裂变和资产分类。 数据保存在浏览器 localStorage，可导出 Markdown / JSON；不联网、不读取 secret、不自动发布。

入口 直接打开 index.html
核心产物 选题矩阵、笔记草稿、复盘记录
安全边界 本地保存，不上传，不发布
已验证工作台截图 10 stages / 20 visible rows

来源：本地工作台 ai-content-workflow/index.html 的示例数据截图。本页只引用本地文件，不上传内容。

10 个工作阶段

01产品卖点提炼

把服务、案例和经验提炼成可信卖点。

02买点映射

把卖点翻译成用户真实在意的场景。

03蓝海机会分析

寻找低竞争、高意图的搜索入口。

04爆文结构拆解

提炼标题、开头、正文和转化结构。

05选题矩阵

组合用户需求、流量入口和内容结构。

06批量笔记生产

按已验证结构生成草稿和封面文案。

07发布

按检查清单记录发布时间、链接和标签。

08数据复盘

跟踪曝光、点击、收藏、评论和线索。

09验证裂变

有效结构换标题、换人群、换场景放大。

10内容资产分类

按主题、阶段和转化价值沉淀资产。

最短使用路径

  1. 1打开入口

    浏览器打开 ai-content-workflow/index.html。

  2. 2载入或填写资料

    输入产品、用户、卖点、需求、流量入口和内容结构。

  3. 3生成选题矩阵

    用需求 x 入口 x 结构生成可验证选题。

  4. 4导出与复盘

    导出 Markdown / JSON，发布后把数据回流到复盘阶段。

输入与输出

基础输入 产品 / 服务、目标用户、核心卖点
矩阵输入 用户需求、流量入口、内容结构
本地状态 localStorage 保存当前工作台数据
导出格式 Markdown / JSON

导出边界

入口：E:\临时项目\ai-content-workflow\index.html
输出：ai-content-workflow-export.md / ai-content-workflow-export.json
执行：浏览器本地逻辑
网络：无
secret/API key：无
发布：不自动发布

审核边界

  • 页面是本地 HTML / CSS / JS 工作台，不调用外部服务。
  • 不读取 secret、API key、账号 Cookie 或外部登录态。
  • 不自动发布内容，不上传文件，不采集外部数据。
  • 导出仅由用户点击触发，格式为 Markdown / JSON。
  • 本次 Open Design artifact 只做说明页，不改原工具执行逻辑。

适合做样例 02 的原因

  • 它已经是前端工作台形态，可以验证“工具说明页 + 工作台截图 + 审核边界”的交付模式。
  • 风险面清楚：无联网、无 secret、无自动发布，主要输出 Markdown / JSON。
  • 业务流程完整：从选题前策略到发布后复盘，适合后续沉淀为工具箱模板。
  • 内部 artifact 可以保留本地路径；对外版需要脱敏路径和示例业务语料。

终审 checklist

  • 用途限定为内部 artifact。
  • 无 form 上传、无外部 HTTP/HTTPS 资源、无 WebSocket。
  • 若对外展示，先移除本地绝对路径和示例业务语料。
  • 运行记录需说明未自动发布、未上传、未读取 secret。
