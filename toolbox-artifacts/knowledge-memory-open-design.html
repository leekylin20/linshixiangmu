Knowledge Memory Layer

本地记忆层导航页

knowledge-memory 是叠加在 E:\临时项目 上的轻量结构化记忆层。 它不替代 Obsidian 主库，也不改动原项目目录；它负责把当前任务、召回规则、schema、JSONL 记录和执行日志整理成后续 agent 可读的索引。

召回流程

  1. 1读活动记忆

    先看当前任务、高优先记忆和默认触发词。

  2. 2读 schema

    按字段抽取样本、项目模块或流程规则。

  3. 3反查主库

    根据图片或任务标签召回 Obsidian 对应专题。

  4. 4区分写入

    单次观察写 JSONL，可复用规律再进入主库。

高优先记忆

  • M001：复杂光影放背景，人物脸部保持干净。
  • M002：直播图必须虚构化，避免真实平台、真实用户名、真实交易数据。
  • M003：人物一致性先锁脸、眼睛、发型识别点和年龄感。
  • M004：夜场低光要保护五官，不吸收低俗语义。
  • M005：美颜调试图重点看发丝边缘、妆面厚度、皮肤质感和补光方式。
  • M006：图片分析结果要反查现有框架，不重新发明提示词。

写入边界

允许可复用提示词框架、光影、构图、妆发和流程规则
只写 JSONL一次性样本观察和低优先级记录
禁止未授权真人身份复刻、真实交易、真实背书和平台伪造数据

重要性评分

0-2  一次性观察，不写主库
3-5  有局部复用价值，写 memory-records
6-8  可形成框架，追加到对应专题库
9-10 改变顶层结构，追加到 Layer 架构或主写法库

审核边界

  • 本页是静态说明页，不读取、改写或追加 JSONL。
  • 不读取 secret、API key、Cookie 或账号登录态。
  • 不上传文件，不联网，不调用外部服务。
  • 不污染 Obsidian 主库；对外展示前需脱敏本地路径。
  • 本轮只做只读核对和 Open Design artifact 交付。

适合做样例 03 的原因

  • 它验证了第三类交付形态：不是工具说明页，也不是工作台说明页，而是知识索引导航页。
  • 风险面清楚：Markdown/JSONL、本地只读、无联网、无 secret、无自动执行。
  • 它和个人工具箱工作台天然相关，可以作为 manifest 和记忆层之间的说明桥梁。
  • 它能把“临时记忆层”和“长期主知识库”的边界讲清楚，避免污染主库。

终审 checklist

  • 用途限定为内部 artifact。
  • 无 script、无 form、无交互输入、无外部 HTTP/HTTPS 资源。
  • 若对外展示，先移除本地绝对路径和主库路径。
  • 运行记录需说明未追加 JSONL、未改 Obsidian 主库、未读取 secret。

  • 为 JSONL 记录生成只读索引表，不提供直接写入按钮。
