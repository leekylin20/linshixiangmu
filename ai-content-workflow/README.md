# AI 内容工作流项目

这是一个面向高价值客群内容生产的本地工作流项目，按截图里的思路拆成：

1. 产品卖点提炼
2. 买点映射
3. 蓝海机会分析
4. 爆文结构拆解
5. 选题矩阵
6. 批量笔记生产
7. 发布
8. 数据复盘
9. 验证裂变
10. 内容资产分类

## 使用方式

直接用浏览器打开 `index.html` 即可。数据会保存在浏览器本地存储里，可以随时导出 Markdown 或 JSON。

## 项目结构

```text
ai-content-workflow/
  index.html              本地工作台
  styles.css              界面样式
  app.js                  工作流逻辑
  data/workflow.json      阶段定义
  prompts/                每个阶段可复制的 AI 提示词
  templates/              复盘、发布、选题模板
```

## 核心原则

- 先验证结构，再批量生产。
- 选题必须同时满足：用户需求、流量入口、内容结构。
- 发布不是终点，复盘结果要回流到选题矩阵。
- 爆款不是单篇笔记，而是一套可复用的表达资产。
