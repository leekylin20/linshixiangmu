# 直播间营销图生成器

纯前端本地获客出图工具，入口文件：

`E:\临时项目\直播间背景生成器\index.html`

## 使用

1. 双击 `启动-直播间背景生成器.bat`。
2. 在弹出的命令行里输入 API Key。
3. 浏览器会自动打开 `http://127.0.0.1:8732/`。
4. 上传或粘贴产品图，上传或粘贴模板图，也可以选择内置模板。
5. 按需调整内缩参考、产品比例、上下锁定、自动审核和自动重试。
6. 点击「生成背景图」。

也可以不用启动脚本，直接用 Chrome 或 Edge 打开 `index.html`，然后点击右上角「API 设置」手动填写：

- API Base URL：`https://dm-fox.rjj.cc/codex`
- 模型：`gpt-image-2`
- 质量：`high`
当前获客版主流程不依赖 API 生成完整海报，网页端会直接合成并导出 `1080x1920` PNG。

## 粘贴图片

- 点击「粘贴产品图」或「粘贴模板图」会主动读取剪贴板图片。
- 也可以先点击对应上传区，再按 `Ctrl+V` 粘贴图片。

## 指令预设

- 补充指令区可以直接输入任意新指令，也可以从预设建议里选择。
- 只有左侧“补充指令”文本框里的内容会作为用户补充指令发送；预设库本身不会自动发送。
- 点「追加」会把输入框里的内容追加到补充指令。
- 点击「编辑预设」进入设置面板。
- 预设格式为每行一个：`名称=指令内容`。

## 当前获客版流程

- 上传产品图，选择模板或上传参考背景。
- 填写顶部标题、副标题、价格 / 权益、卖点、左侧徽章和底部服务栏。
- 网页端用真实字体在 Canvas 上渲染文字，API 不负责生成中文文案。
- 产品图由网页端放置，可调产品大小、左右、上下位置。
- 内缩参考用于控制标题、徽章、权益卡、底部栏等贴片离边缘的距离。
- 点击「生成营销图」后直接合成 `1080x1920` PNG，可一键下载用于小红书 / 抖音 / 私域获客。
- API 能力保留为后续增强：背景生成、背景替换、质感增强、局部修复和高清放大，不作为当前主流程。

## 高级定制流程定位

- 客户确认方向后，再进入 PS 手动分层、API 空场修复、4K 精修和 PSD / 分层文件交付。
- 空场不是重新生成背景图，而是基于已有成图涂抹选区后，调用 API 只编辑蒙版区域并补全背后背景。
- 4K 放大用于付费定制、高清交付或大屏直播背景，不影响当前 1080 快速出图。

也可以在本目录执行：

```powershell
set LIVESTREAM_BG_API_KEY=sk-xxxx
node server.js 8732
```

然后访问 `http://127.0.0.1:8732/`。

## 说明

- 使用启动脚本时，API Key 只在命令行当前进程里使用，不写入项目文件；历史记录、自定义模板保存到浏览器 IndexedDB。
- 内置模板图来自 `E:\obsidian\绿幕直播间种子文件夹`，已复制到 `assets\templates`。
- 当前主流程由浏览器 Canvas 合成 1080 竖图；API 设置保留给后续背景增强、局部修复和高清交付能力。
- 若浏览器直接打开时遇到 IndexedDB 或本地资源限制，可在本目录启动 `server.js` 后访问。
