# Global Rules

Every positive prompt must include:

- vertical 9:16 Douyin live-commerce green-screen room mother image
- 1080x1920 composition
- unbranded generic category product
- no real brand, no logo, no trademark, no price, no platform UI
- product package only shows category name, flavor/type, and short generic selling points
- adult livestream host
- real sitting or standing live-selling camera view
- camera height about 125cm
- full-frame equivalent 45-50mm lens
- slight downward angle 2-3 degrees
- no wide-angle distortion
- table top visible around 25-35%
- product front label faces camera
- realistic contact shadow and landing point
- clean foreground live-commerce table
- clear product display zone
- reusable layer-friendly composition
- suitable for later split into empty background layer, table layer, product layer, title/mask layer

The workbench sanitizes user-provided product words into unbranded generic category wording. It must not inherit real brand names, logos, trademarks, prices, platform UI, celebrity names, influencer names, shop names, or real promotional event names.
