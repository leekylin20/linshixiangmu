## 这个库是什么

这是一个 AI 短剧自动化生产平台，项目名是 Huobao Drama。它是 TypeScript 全栈项目，前端使用 Nuxt 3 + Vue 3，后端使用 Hono + Drizzle ORM + Mastra AI Agents + SQLite。

它的目标流程是从小说/创意生成剧本，再进行角色提取、分镜拆解、角色与场景图生成、TTS 配音、FFmpeg 视频合成和整集导出。

## 重要提示

AI 服务的 API Key 和模型参数需要在 Web 界面的“设置”页面配置。未配置 API Key 时，涉及模型调用的生成流程无法真正完成。

本项目依赖原生 SQLite 模块和 FFmpeg。为避免污染系统环境，本机使用项目内 `.runtime` 目录提供 Node 22 和 FFmpeg。
