## 三、图像分析时的框架匹配顺序

```text
1. 先判断图片属于哪种大类：
   直播间 / 自拍 / 棚拍 / 夜场 / 校园 / 新中式 / 艺术海报 / UI截图

2. 再判断最强信号：
   人物脸 / 光影 / 房间 / 妆发 / 构图 / UI / 产品 / 情绪

3. 去对应库找框架：
   人物 → 9段描写语法
   光影 → 光影提示词库
   房间 → Layer 3 空间层
   构图 → 主写法库中的构图和镜头模块
   妆发 → 主写法库 + Chryzleenprompt / Ciri / VIBEQUIRKLABS
   直播 UI → joshesye / Shinning1010

4. 最后输出：
   图片观察
   可复用框架
   缺失框架
   建议追加到库里的新规则
```
