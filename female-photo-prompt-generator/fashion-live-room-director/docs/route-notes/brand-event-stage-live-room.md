# 品牌活动舞台型直播间 Route Notes

## 为什么单独开 route

该构图服务的是品牌信任、官方活动感、多人主持和小体积产品展示。
它和女装站播的 L 型转角构图不同。

女装站播重点：
- 全身比例
- 腰线
- 裙摆
- 裤脚
- 上身效果
- 主播讲解区

品牌活动舞台重点：
- 品牌门头
- 官方活动感
- 主持人与嘉宾关系
- 产品台成交锚点
- 手机直播 UI 适配
- 品牌资产露出

## 核心构图名称

品牌门头式中轴舞台构图  
Brand Facade Center-Stage Live Room

## 适用场景

- 美妆
- 护肤
- 香水
- 珠宝
- 高客单品牌专场
- 超级品牌日
- 新品发布
- 明星嘉宾直播
- 专家讲解直播

## 不适用场景

- 牛仔裤站播
- 连衣裙试穿
- 防晒服试穿
- 棉麻女装
- 需要完整展示人体比例的服装类直播
