# 新中式直播间 Route Notes

## 为什么单独开 route

该 route 服务的是服装讲解型直播间，但空间气质需要新中式、宋式、东方雅致陈设。
它不同于女装 L 型转角通用模板，也不同于品牌活动舞台型和绿幕生态型。

核心不是古风摄影棚，而是：

真实可开播的室内直播间 + 新中式 / 宋式 / 东方雅致陈设系统。

## 一句话定义

新中式直播间：以真实室内直播间为基础，用暖木、留白、屏风、帘幕、东方灯具、木柜、竹影和少量器物建立安静克制的东方陈设感，让服装获得温润、材质化、气质化表达；场景必须服务服装展示，避免走向古风棚拍、婚礼布景、茶馆陈列或博物馆式过度装饰。

## 适用品类

- 新中式女装
- 棉麻女装
- 宋式美学服装
- 设计师女装
- 文艺宽松款
- 气质型秋冬女装
- 香云纱 / 刺绣 / 提花 / 苎麻类服装
- 中式家居服
- 部分饰品 / 茶生活相关品类

## 不优先适合

- 强都市牛仔裤
- 防晒服
- 强运动休闲
- 欧美辣妹风
- 医研风
- 活动舞台型品牌直播间

## 空间关键点

- 真实室内房间逻辑
- 竖版 9:16
- 中景主播讲解区清楚
- 全身服装展示清楚
- 完整地面延伸
- 后景墙面 / 垂帘 / 屏风 / 木柜等结构
- 场景层次主要放在后景与侧边
- 中心区域必须留给主播和服装

## 子方向占位

### song_minimal_home

宋式极简居家型：留白更多，帘幕更轻，屏风更简，适合棉麻和文艺女装。

### oriental_display_home

新中式陈设型：陈设更完整，屏风 / 灯具 / 花器更明显，适合设计师款和气质型服装。
