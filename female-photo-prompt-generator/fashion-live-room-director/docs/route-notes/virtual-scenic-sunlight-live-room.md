# 绿幕建模生态场景直播间 Route Notes

## 为什么单独开 route

该 route 服务的是绿幕抠像、虚拟建模、假阳光和自然生态氛围。
它和真实室内 L 型转角站播不同，也和品牌活动中轴舞台不同。

核心目标不是还原真实房间，而是用可控虚拟空间制造：

- 季节感
- 户外感
- 自然感
- 轻生活方式
- 产品场景联想

## 核心构图名称

绿幕建模生态场景直播间  
Virtual Scenic Sunlight Live Room

## 适用场景

- 防晒服
- 夏装
- 户外休闲
- 运动休闲
- 棉麻女装
- 森系女装
- 鞋服
- 帽子
- 自然护肤
- 香氛洗护

## 不适用场景

- 需要精准裤型展示的牛仔裤
- 严肃通勤服装
- 高级定制感女装
- 大牌品牌活动舞台
- 多人发布会直播

## 关键风险

- 人像像被贴在背景上
- 光影方向不一致
- 脚下漂浮
- 虚拟空间比例错误
- 绿色过饱和
- 变成热带度假场景
- 变成游戏环境或幻想森林
- 景观抢走产品主体
