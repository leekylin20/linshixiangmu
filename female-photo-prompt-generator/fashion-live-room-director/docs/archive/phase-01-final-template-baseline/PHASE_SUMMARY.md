# Phase 01 - Final Template Mode Baseline

## 阶段目标

将女装直播间视觉生成系统从多层规则拼接，调整为“最终模板 + 少量变量替换”的稳定生图模式。

## 解决的问题

- 旧 prompt 过长，约 700-900 英文词。
- route / sceneStyle / layoutVariant 原文整段拼接。
- 规则互相覆盖，导致画面身份不稳定。
- 直播信号被模型画成价格牌、促销牌、灯架或设备角。
- 防晒服容易被秋冬深木规则带偏。
- 牛仔裤负面词曾错误否定直播间身份。
- checklist 正负混搜导致假阳性。

## 当前已解决

- `compactImagePrompt` 走最终模板。
- 3 个模板均小于 300 英文词。
- 三类品类展示点通过审计。
- 禁止词检查通过。
- 空间骨架通过。
- 不再把 route / sceneStyle / layoutVariant 原文拼进最终 prompt。
- 未新增总监层。
- 未新增 rewrite 层。

## 当前阶段结论

最终模板路线成立，可以作为后续扩展基础。

后续不要轻易改动主空间骨架，只允许通过变量库丰富软装、材质、摆件和品类细节。
