# Prop Accessory Library
# 女装直播间摆件变量库

用途：
控制小摆件，摆件必须少而准，用于提升空间质感和产品价格感。

## premium_props 中高客单 / 牛仔裤 / 都市轻奢

- small black handbag
- champagne metal tray
- ceramic vase
- abstract sculpture
- leather-bound books
- dark glass candle cup
- matte black decor object

## fresh_summer_props 防晒服 / 春夏清爽

- clear glass vase
- small green plant
- pale ceramic pot
- linen basket
- light wood tray
- fresh branch arrangement
- pale green plant accent

## soft_feminine_props 连衣裙 / 法式 / 轻生活

- small flower vase
- cream ceramic bowl
- woven basket
- soft book stack
- round mirror
- delicate table lamp
- pastel flower branch

## natural_linen_props 棉麻 / 自然风

- rattan basket
- unglazed ceramic vase
- linen folded fabric
- wooden tray
- dried branch
- woven mat
- handmade ceramic cup

## 选择规则

每张图最多选择 2-4 个小摆件。

摆件必须位于：

- 边柜
- 边几
- 窗边
- 背景层
- 辅助陈列区

摆件禁止出现在：

- 主播脚下中心区
- 服装主体前方
- 裤脚 / 裙摆 / 袖口遮挡区

## 禁止

- 大量花艺
- 满桌摆件
- 复杂杂货铺
- 品牌 logo
- 真实品牌名
- 奢侈品明显商标
- 过季网红摆件
- 道具抢主体
- 价格牌
- 促销板
- 信息牌过大
