# Soft Furnishing Library
# 女装直播间软装大件变量库

用途：
控制直播间软装大件，只能低密度选择，不能变成普通家居样板间。

## seating 座椅类

- leather single chair
- rattan lounge chair
- soft cream armchair
- low upholstered bench
- small stool
- woven accent chair
- slim wooden chair

## cabinet 柜体类

- low walnut cabinet
- rattan door sideboard
- cream low cabinet
- slim display console
- small wood sideboard
- pale oak cabinet
- dark wood low cabinet

## table 边桌类

- small round side table
- stone top side table
- walnut side table
- minimal pedestal table
- slim metal side table
- light wood side table

## textile 织物类

- linen curtain
- sheer curtain
- woven rug
- textured carpet
- cotton-linen throw
- natural fiber rug
- soft neutral rug

## wall_decor 墙面装饰类

- abstract framed art
- botanical line drawing
- minimal photography print
- soft color block artwork
- small wall lamp
- warm wall sconce

## 选择规则

每张图最多选择：

- 1 个 seating
- 1 个 cabinet
- 1 个 table
- 1 个 textile
- 1 个 wall_decor

## 禁止

- 家具过多
- 沙发组合
- 大量椅子
- 客厅化过强
- 家具挡住服装主体
- 家具占据中心讲解区
- 软装抢产品
- 普通住宅感过强
