# product-driven-scene-design-rule
# 产品导向场景赋能规则

## 核心判断

直播间场景设计优先跟产品走，而不是跟下单人群标签走。

场景不是跟人群喜好走，而是跟产品走。人群只影响质感和客单价层级，不能反向绑架产品场景。

不要因为用户人群是“都市丽人 / 小清新 / 学生 / 熟龄 / 宝妈”就直接套对应风格。

正确路径是先判断产品本身：

- 品类
- 季节
- 材质
- 价格带
- 穿着场景
- 产品气质
- 主推卖点
- 视觉赋能方向

然后再决定空间风格、主色调、材质、层次和摆件。

## 产品优先原则

场景必须服务产品，而不是服务抽象人群画像。

错误路径：

先判断人群喜好 -> 套风格 -> 产品被场景带偏。

正确路径：

先判断产品属性 -> 选择场景气质 -> 再用客单价和人群层级调整质感。

## 场景赋能逻辑

场景的作用是给产品做视觉赋能。

场景应该强化：

- 产品价格感
- 产品季节感
- 产品材质感
- 产品穿着场景
- 产品风格气质
- 产品成交信任感

场景不能抢产品主体。场景不能为了讨好人群而让产品失真。

## 设计路径

做直播间场景时，优先按以下顺序思考：

1. 产品品类
2. 季节属性
3. 材质和颜色
4. 价格带 / 客单价层级
5. 产品气质
6. 空间主色调
7. 空间层次
8. 赋能家具和陈列
9. 小摆件

不要先根据人群标签选择场景。

## 主色调

背景主色调最重要，因为直播间不能经常更换。主色调必须能长期承载该品类和价格带。

判断维度：

- 产品主色
- 季节
- 价格带
- 品牌气质
- 是否需要显高级
- 是否需要显清爽
- 是否需要显温暖
- 是否需要显专业

## 空间层次

空间层次优先于小摆件。

可使用：

- 大空间转角
- 侧墙
- 地面纵深
- 大木柜
- 沙发
- 单椅
- 岛台
- 边柜
- 低密度陈列
- 侧向窗光
- 后景生活层

空间层次的目标：让直播间像真实可进入的空间，而不是一面背景墙。

## 赋能家具

中高客单价：

- 深木柜
- 皮质单椅
- 艺术画
- 金属边几
- 小奢包袋
- 质感台灯
- 低饱和墙面

清爽夏季品：

- 浅木
- 米白
- 亚麻
- 轻窗帘
- 植物
- 大面积留白
- 浅色地面

棉麻 / 舒适品：

- 藤编
- 亚麻
- 暖白墙
- 原木柜
- 低矮软装
- 生活方式角落

牛仔裤 / 通勤：

- 暖木或深木
- 灰墙
- 皮椅
- 小型边柜
- 少量金属元素
- 克制低密度陈列

## 小摆件

小摆件最后考虑。小摆件最容易过时，也最容易让画面变杂。

小摆件必须根据当前流行元素、产品价格带、季节、产品气质和主色调选择。

不能随便堆摆件，不能让摆件抢主体，不能把场景做成样板房杂货间。

## 客单价赋能规则

低客单价：干净、明亮、轻量、少道具、不强行奢华，强调实穿、好搭、性价比。

中客单价：有生活方式感、有空间层次、有少量质感家具、色调统一、画面干净。

中高客单价：加入小奢元素，强化材质感和空间质感，可使用深木、皮质、艺术画、包袋、金属细节，但仍然低密度。

高客单价：场景必须有品牌感，家具和材质克制高级，背景稳定，摆件少而准，不能像低价门店陈列。

## 季节赋能规则

夏季产品：清凉、通透、浅色、轻盈、侧窗光、植物、浅木 / 米白 / 亚麻，不厚重。

冬季产品：暖光、深木、皮质、厚重墙面、暖色灯带、沙发 / 单椅、小奢元素，不要太冷清。

通勤四季款：稳定主色、灰木 / 暖木 / 米灰、大空间转角、干净地面、低密度陈列，强调品质和实穿。

## 牛仔裤示例规则

牛仔裤不直接按“都市丽人 / 小清新”人群分场景。

冬季 / 深色 / 中高价牛仔裤：深木、灰墙、小奢元素、皮质单椅、艺术画、边柜、暖光、都市通勤质感。

夏季 / 浅色 / 清爽牛仔裤：浅木、米白墙、侧窗光、清爽植物、亚麻软装、轻生活方式感。

基础低价牛仔裤：干净真实直播间、低密度挂样、强调裤型和实穿、不强行小奢。
