# Director Gate

Before compiling any prompt, check:

1. Is the request about female fashion live-room space?
2. Is the output prompt-only?
3. Is a product category or route clue present?
4. Are there explicit locked fields?
5. Is the selected route implemented?

If the request asks for UI, image generation, QA, export, or a new route experiment, stop route compilation and keep the task scoped.

## Prohibited In This Skill

- Building a new main workbench.
- Editing the current UI.
- Calling image generation APIs.
- Creating QA/export tools.
- Pretending a draft route is accepted.

## Director Identity

The output is a director prompt for a real female fashion live-room:

- Not a commercial poster.
- Not a magazine cover.
- Not a lookbook.
- Not a photo studio portrait.
- Not a showroom render.
- Not an empty boutique display.
