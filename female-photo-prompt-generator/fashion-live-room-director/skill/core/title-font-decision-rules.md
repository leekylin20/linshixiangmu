# Title And Text Decision Rules

This project does not prioritize poster text design.

Text is optional and secondary.

## Rule

The product and room must remain primary.

If text appears, it is an information layer, not a poster headline.

## Allowed

- Tiny brand cue.
- Simple room label.
- Reserved area for later UI/text.
- Minimal non-intrusive live-room information layer.

## Not Allowed

- Large poster headline.
- Typography-driven composition.
- Price-poster composition.
- Full-screen sales stickers.
- Product hidden behind text.
- Title becoming main visual subject.

## Default

For prompt-only room generation:

Prefer no visible text, or only reserved clean areas.

Use room structure, product display, and host action to communicate the scene.
