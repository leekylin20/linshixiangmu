# Spatial Perspective Rules

This module is a fixed hard-lock module.

It must stay in the same position in future iterations:

- Output card 4 in the main workbench.
- Late-stage constraint in final compiled prompt.

All route rules must obey this module.

## Camera Defaults

- Vertical 9:16 unless user locks another ratio.
- Full-frame 35mm by default.
- Real vertical live-room fixed camera.
- Level camera.
- Eye-level or slight eye-level.
- No top-down shot.
- No low-angle shot.
- No exaggerated wide-angle.
- No leg stretching.

## Perspective Lock

Must include:

- Stable vertical walls.
- Stable door frames.
- Stable window frames.
- Stable cabinet edges.
- Stable screen edges.
- Horizontal clothing racks.
- Unified floor and wall perspective.
- Real furniture scale.
- Host feet grounded.
- No collage-like space.

## Depth Lock

Every live-room scene must establish:

1. Foreground floor layer.
2. Midground host layer.
3. Background room layer.

The floor must extend from the camera foreground to the host feet, and then continue into the background.

The host must stand in the room's mid-zone, not against the wall, curtain, brand wall, grid wall, or background board.

Keep 1.5-2.5 meters of real space behind the host.

Full-body host height should be about 68%-76% of frame height, never above 80%.

## Room Box

The space is not a single background wall.

It must look like a complete indoor room box:

- Back wall.
- At least one side wall or corner.
- Floor depth.
- Partial ceiling or overhead lighting structure.
- Furniture or display elements with side recession.

## Negative

Avoid:

- Person standing against wall.
- Person against curtain.
- Single background board.
- Photo-studio curtain backdrop.
- Shallow-depth flat background.
- No foreground floor.
- Room filled by person.
- Only wall and person.
- Insufficient room depth.
- Background like flat poster.
