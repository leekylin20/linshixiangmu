# 架构说明

## 1. 数据源层

数据源层负责连接外部接口。建议按用途拆开，而不是按供应商堆在一起。

| 层面 | 数据源 | 适合内容 |
|---|---|---|
| 行情 | 通达信 | 实时价格、盘口、K 线、逐笔成交 |
| 行情 | 腾讯财经 | PE、PB、市值、换手率等计算指标 |
| 研报 | AKShare / 东方财富 | 研报列表、PDF、机构观点 |
| 语义搜索 | i问财 | 自然语言选股、跨主题检索 |
| 新闻 | 财联社 / 东方财富 | 快讯、个股新闻、全球资讯 |
| 基础数据 | 通达信 / AKShare | 公司概况、股东、财务摘要 |
| 公告 | 巨潮资讯 / 通达信 | 公告、分红、股东决议摘要 |
| 信号 | 同花顺热点 | 题材归因、涨停原因、强势股线索 |

## 2. 处理层

处理层把原始数据转成知识对象：

- 清洗：统一字段、时间、股票代码、来源。
- 去重：同一事件可能来自公告、新闻、快讯多个渠道。
- 摘要：把长研报、长公告、长新闻压缩成可读摘要。
- 实体识别：识别公司、股票、行业、题材、机构、人物。
- 事件抽取：把内容归类为订单、业绩、并购、政策、减持等。
- 标签归因：补充题材、产业链位置、影响方向、置信度。

## 3. 第三大脑层

第三大脑层不保存所有原始数据，只保存值得长期回忆和检索的知识。

建议拆成 7 类记忆：

| 记忆类型 | 内容 |
|---|---|
| company_profile | 公司档案 |
| industry_profile | 行业档案 |
| topic_profile | 题材档案 |
| event | 新闻、公告、行情异动事件 |
| research_note | 研报摘要与机构观点 |
| signal | 热点归因、强势股线索 |
| query_note | i问财等语义搜索结果沉淀 |

## 4. 推荐入库策略

行情数据：

- 原始 K 线、盘口、逐笔成交留在行情数据库或缓存。
- 第三大脑只保存异动事件和解释。

研报数据：

- 保存研报标题、机构、分析师、发布时间、摘要、核心假设、风险提示。
- PDF 原文保存路径或 URL，不必全文塞进记忆库。

新闻数据：

- 快讯和个股新闻先抽取事件。
- 只保存有明确实体、明确影响、明确时间的内容。

公告数据：

- 公告是高可信源，优先入库。
- 保存公告类型、关键字段、影响判断和原文链接。

热点归因：

- 保存题材、触发原因、相关个股、热度变化。
- 长期积累后可以形成市场叙事图谱。
